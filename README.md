# LumenBlock Puzzle

Glow-themed block puzzle mobile game featuring smooth drag-and-drop placement, combo scoring, and lightweight local persistence.

> 🌐 **JBM SOFT:** [https://jbmsoft.co.kr](https://jbmsoft.co.kr)  
> 🔒 **Note:** Public portfolio showcase. Commercial ad/IAP keys and release signing configs are excluded.

---

## ✨ Key Features

- **Grid & Collision Engine:** Fast 2D board validation, line-clear detection, and combo multipliers
- **Responsive Touch Dragging:** Offset-compensated touch previews for accurate finger placement
- **Audio & Haptic Feedback:** Synchronized sound effects and subtle vibration cues
- **Offline-First Persistence:** Local high-score and board-state recovery

---

## 🛠 Tech Stack

- **Framework:** Flutter / Dart
- **Architecture:** Decoupled board state controller + custom canvas/grid renderer
